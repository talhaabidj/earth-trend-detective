Where is it changing?

Test every grid cell around your place at once, for the question you chose above. Click a cell to see its full result.

Each cell is tested on its own. Because so many cells are tested at once, a cell only counts as a clear trend if it also passes a false discovery check (Benjamini-Hochberg, 5%), so chance results are filtered out.

How it works

  1. Data. Monthly values from NASA POWER, which serves the NASA MERRA-2 reanalysis and CERES satellite products, 1981–2025, for any point on Earth. A wider area is an average of grid cells weighted by their size.
  2. Seasons removed. We work out each month's usual value and subtract it, so a hot summer is not mistaken for warming. These differences are the anomalies.
  3. Test 1: seasonal Mann-Kendall. Compares every January with every other January (and so on). It only asks "up or down?", so outliers do not fool it. Its rate is the median (Sen) slope.
  4. Test 2: least-squares on anomalies. Fits a straight line, but counts fewer independent months when one month's value carries over into the next (autocorrelation). Without this, many trends look more certain than they are.
  5. Many tests at once. The map tests hundreds of grid cells, so it filters out chance results with a false discovery check (Benjamini-Hochberg).
  6. Verdict. "Yes" only when both tests agree at the 5% level. "Maybe" when they disagree. "Not significant yet" comes with an estimate of how many more years of data would settle it (Weatherhead et al., 1998).

Limits: POWER is a model-based product at about 50 km, not a weather station. A trend is a straight-line summary; real changes can speed up, slow down or jump. The tool finds change; it does not by itself prove the cause.
