    Use it in class (15 minutes)

    A short activity for school or college students. No sign-up, works on phones.

    1. Guess first. Ask: "Is our town getting hotter?" Write down the guesses.
    2. Test it. Look up your town. Check the average, the daytime high and the night-time low. Do they agree?
    3. Compare. Add a second place far away. Why might the answers differ?
    4. Discuss. What does "not significant yet" mean? Why do scientists wait for more data before saying yes?

    How the detective works

    Every step can be checked. The code and the tests are open.

    1. Data. Monthly values from NASA POWER, which serves the NASA MERRA-2 reanalysis and CERES satellite products, 1981–2025, for any point on Earth. A wider area is an average of grid cells weighted by their size. The greenness examples use the MODIS instrument on NASA's Terra satellite.
    2. Seasons removed. We work out each month's usual value and subtract it, so a hot summer is not mistaken for warming.
    3. Test 1: seasonal Mann-Kendall. Compares every January with every other January (and so on). It only asks "up or down?", so outliers do not fool it. Its rate is the median (Sen) slope.
    4. Test 2: straight line with memory. Fits a line, but counts fewer independent months when one month's value carries over into the next. Without this, many trends look more certain than they are.
    5. Verdict. "Yes" only when both tests agree at the 5% level. "Maybe" when they disagree. "Not significant yet" comes with an estimate of how many more years of data would settle it (Weatherhead et al., 1998).
    6. Many tests at once. The map tests hundreds of grid cells, so it filters out chance results with a false discovery check (Benjamini-Hochberg).

    Limits: POWER is a model-based product at about 50 km, not a weather station. A trend is a straight-line summary; real changes can speed up, slow down or jump. The tool finds change; it does not by itself prove the cause.

    Words explained

    Trend
    A change that keeps going in one direction over many years.
    Anomaly
    How different a month was from what is usual for that month.
    Significant
    Unlikely to be chance: a result this strong would appear less than 1 time in 20 if nothing were changing.
    95% range
    The span of rates that fit the data well. If it includes zero, the trend is not proven.
    Grid cell
    One square of NASA's data, about 50 km wide. A city is usually inside one cell.
    Reanalysis
    A weather model run over the past and corrected with satellite and ground measurements (here NASA's MERRA-2).
