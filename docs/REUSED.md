# Prior work reused

This project was started on 14 Nov 2026 at the NASA Space Apps Challenge. The repository was
created after the event opened (09:00 PKT, the Team Owner's local time).

The team owner has an earlier open-source project, AquaLens (MIT licence), which also does trend
tests on satellite data. **No AquaLens code has been copied into this repository.** If any is
copied later, it will be listed here with the source file, its commit hash and the MIT notice.

Third-party libraries and data are listed in [DATA_SOURCES.md](DATA_SOURCES.md) and in the README.
