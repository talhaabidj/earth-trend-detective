# Use of Super Intelligence (SI) tools

The NASA Space Apps 2026 rules ask every team to say clearly where and how SI tools were used, and
to mark SI-generated code and data in text and metadata. This file is that record. It is kept up to
date during the event.

## Tools used

- **Claude Code (Anthropic, model Claude Opus 5.5)**, a coding assistant.

## What the SI did

- **Before the event (31 Oct – 1 Nov 2026):** at the team owner's request, Claude researched the
  rules, past winners and NASA data services, and drafted a private planning document that included
  a possible product concept. No code was written before the event.
- **During the event:** the team decided the concept and the demo places in their own words (see
  the project page). Claude wrote most of the code under the team's direction: the statistics engine
  (`engine/`), the browser copy of it (`web/js/stats.js`), the data download scripts and the web
  page. Claude also drafted documentation text, which the team reviewed and edited.
- **Data:** no data was generated by SI. Every number in the app comes from NASA POWER or MODIS
  data, processed by the code in this repository. SI does not produce any statistic, p-value or
  verdict at run time; the verdict text is a fixed template filled with computed numbers.

## How SI-written files are marked

Every source file written with SI help starts with a one-line note pointing to this file.
