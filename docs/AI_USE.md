# Use of Super Intelligence (SI)

NASA Space Apps 2026 asks teams to say where and how SI tools were used, including for code, text
and audio. This is that disclosure.

## Tools

- **Claude Code** (Anthropic): coding and writing assistant.
- **Kokoro-82M v1.0** (open-weight text-to-speech, Apache-2.0, run locally): demo video voice-over.

## Where SI was used

- **Before the event (31 Oct – 1 Nov 2026):** Claude researched the rules, past winners and NASA
  data services and drafted a private plan with a possible concept. No code or data work.
- **Concept:** at Talha's request, Claude drafted the written concept (what the tool is, who it is
  for, the example places, the name), based on a NASA POWER trend scan it ran.
- **Code:** Claude wrote nearly all of the code (`engine/`, `web/`, `tools/`), following the
  team's instructions and corrections.
- **Text:** Claude drafted the README, docs, example texts and project page text; the team reviewed them.
- **Demo video:** Claude wrote the scripts that build it from screenshots of the live site. The
  English voice-over is SI-generated with Kokoro; the video says so on its first and last card and
  in its description.

## Where SI was not used

- No data was generated by SI. Every number comes from NASA POWER or MODIS data, processed by the
  code here and checked by tests.
- No SI runs in the website. Verdicts are fixed templates filled with computed numbers.
- No SI-generated images or music.

  decisions during the build (data, scope, fixes after review); checks the results and submits.
- **Kainat Ijaz:** her part will be listed here when it is done.
