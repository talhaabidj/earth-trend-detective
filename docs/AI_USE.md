# Use of Super Intelligence (SI) tools

The NASA Space Apps 2026 rules ask every team to say clearly where and how SI tools were used,
including SI-written code and text. This is that record.

## Tool

- **Claude Code** (Anthropic), a coding assistant, model Claude Opus 5.5.

## What Claude did

**Before the event (31 Oct – 1 Nov 2026).** At Talha's request, Claude read the rules, past winning
projects and NASA data services, and drafted a private planning document. That document included
a possible product concept. No code was written and no data was downloaded before the event.

**During the event (14–15 Nov 2026).**
- **The concept.** At Talha's request, Claude drafted the written concept (what the tool is, who it
  is for, which places the examples use, the name and tagline), based on a trend scan of NASA POWER
  data that Claude also ran. Talha asked for this. We say it plainly because the rules say SI
  should not be used to come up with the idea.
- **The code.** Claude wrote nearly all of the code in this repository, following the team's
  instructions and corrections: the Python statistics engine and its tests (`engine/`), the
  browser version of the engine and the web page (`web/`), and the data download and example
  scripts (`engine/scripts/`).
- **The text.** Claude drafted the README, these docs, the example texts and the project page text.
  The team reviewed and edited them.
## What SI did not do

- **No data was generated by SI.** Every number comes from NASA POWER or MODIS data, processed by
  the code in this repository, and checked by tests.
- **No SI runs in the website.** Verdicts are fixed sentence templates filled with computed numbers.
- No SI-generated images, logos or audio are used anywhere in the project.

## What the team did

- **Talha Abid:** chose the challenge, the event and the team name; asked for the concept; made the
  decisions during the build (which data to use, what to cut, which fixes to make after a review);
  checks the results and submits the project.
- **Kainat Ijaz:** team member since 1 Nov 2026 (in the US, working in a later time zone). Her part
  will be listed here when it is done.

This file is updated before submission so that it matches what actually happened.
